## Sanmarks sp. z o.o. - IT

Von 2023 bis 2026 war ich bei Sanmarks sp. z o.o. und Tele-centrum sp. z o.o. tätig. Heute erbringe ich für diese und andere Unternehmen Softwareentwicklungs- und Rechtsdienstleistungen.

- Optimierung bestehender Systeme
- Aufbereitung der zentralen Unternehmensdatenbank und Steigerung ihres Werts durch die Zusammenführung von Datenbanken aus drei verschiedenen Quellen (insgesamt 2,5 Millionen Datensätze) in eine normalisierte, duplikatfreie Form

## Kommerzielle Projekte

**Eventmanagement-System**
*Django, HTMX*
Ein umfangreiches, in Django entwickeltes CRM-System zur gleichzeitigen Verwaltung von Mitarbeitenden und Unternehmen bei mehreren Veranstaltungen. Organisatoren können damit unter anderem Daten zu Subunternehmen bündeln, Zugänge und Armbänder verwalten; der Sicherheitsdienst kann Mitarbeitende über ein QR-Code-System identifizieren.
Das System wurde erfolgreich bei großen Veranstaltungen eingesetzt, darunter das Konzert von Ed Sheeran in Wrocław und Drift Masters im Nationalstadion in Warschau.

**Gesprächsanalyse für Callcenter**
*Whisper API, LLM (RAG), Django, Celery, Redis*
Eine Anwendung zur Analyse von Callcenter-Gesprächen und zur Bewertung der Arbeit von Beraterinnen und Beratern auf Grundlage von Audiotranskriptionen und LLM-generierten Bewertungen. Sie wurde zunächst als internes Startup-Projekt entwickelt und später verkauft.

Vor Kurzem habe ich Version 2.0 erstellt und dafür neue KI-Funktionen eingesetzt, die zuvor nicht verfügbar waren: Structured Outputs und Sprecherdiarisierung für die polnische Sprache. Um Abhängigkeiten zu reduzieren, habe ich Redis und Celery durch eigene Implementierungen ersetzt.

**Text-to-Speech-Anwendung für ein Krisenmanagementzentrum**
*Google Cloud Text-to-Speech, Django*
Ein System zum Versand gesprochener Mitteilungen an Einwohner per Voice Mailing. Die Sprache wird über die API der Google Cloud Platform erzeugt. Meine Aufgabe war die Entwicklung dieser Komponente und ihre Integration in die vorhandenen Unternehmenssysteme.

**Website für den Verkauf von Datenbanken**
*Django, DRF*
Eine Verkaufswebsite mit mehreren interessanten Formen der Datenpräsentation. Besonders ist die Trennung von serverseitiger Anwendung und Frontend auf zwei verschiedene Server (PythonAnywhere und nazwa.pl), die über eine API verbunden sind. Dadurch kann der Kunde moderne Technologien nutzen, ohne die Struktur der CNAME-Weiterleitungen unnötig zu verkomplizieren.

**Verwaltung von Unternehmenswebsites**
*WordPress, HTML, CSS, JS*
Ich habe Websites auf Basis von WordPress, Django und klassischem Code erstellt, bearbeitet und verwaltet.

**Website des Folkowisko-Festivals**
Ich entwickelte ein System zur Veröffentlichung von Workshop-Informationen (WordPress, Google Apps Script) und zu ihrer Anzeige für Festivalteilnehmende über eine Starlink-Verbindung.
